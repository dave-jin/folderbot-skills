# 시작 브리핑 형식 — /start 6단계

이 형식은 **축 → 덩이 → 행동** 순서로 쓴다. 여러 일을 동시에 굴리는 사람에게 남는 것은 이 순서뿐이다. 항목을 늘린다고 친절해지지 않는다. 늘리면 아무것도 남지 않는다. 한 번에 기억할 것은 3개까지이고, 한 화면에 3덩이를 넘기지 않는다.

브리핑은 **채팅 답변에 쓰고**, 같은 내용을 `todo.md` 맨 위 인용 블록으로도 남긴다. 다음 세션이 그것을 이어받는다.

## 템플릿

```markdown
# ▶ <프로젝트> 시작 브리핑 — YYYY-MM-DD

**지난 N일 동안 달라진 것** (측정 실패: 없음)
- <날짜> <누가> <무엇> — 출처
- <날짜> <누가> <무엇> — 출처
- (없으면) 변화 없음. 마지막 활동은 <날짜> <무엇>.

**축**: <왜 지금 이것인지 한 문장>

**지금 당장 하나** ⏱ <소요>
<할 일 한 문장>
→ 첫 5초: <열 파일 / 연락할 사람 / 칠 명령>

**그다음** (최대 2덩이)
- **<덩이 이름>** ⏱ <소요> — <무엇> → 첫 5초: <행동>
- **<덩이 이름>** ⏱ <소요> — <무엇> → 첫 5초: <행동>

**결정이 필요한 것**
1. <질문> — ⓐ <선택지> ⓑ <선택지>
2. …
```

## 각 칸을 쓰는 법

**달라진 것** — 3줄 이내로 쓴다. 4단계 표에서 **사용자의 다음 행동을 바꾸는 것**만 고른다. 「9/3 고객사 담당자가 보고서 형식을 문장으로 줬다」는 들어가고 「9/2 안부 인사」는 안 들어간다. 측정 실패가 있으면 괄호 안에 채널과 이유를 적는다.

**축** — 한 문장이다. 날짜에 의미를 붙인다. ✗ 「9/12 마감」 ✓ 「9/12 초안이 나머지 일정 전체를 여는 유일한 창이다」. 축이 없으면 아래는 그냥 목록이 되고, 목록은 기억에 남지 않는다.

**지금 당장 하나** — 긴급도(기한 · 상대가 기다리는가)와 중요도(CLAUDE.md 목적을 직접 앞당기는가)가 **둘 다 높은 것**을 고른다. 소요 시간은 실제 감각대로(15분 · 1시간 · 반나절) 적는다. 첫 5초 행동은 손이 바로 움직이는 단위로 쓴다. 「`03_보고서/A사_초안.md` 를 연다」 · 「담당자에게 '9/12 초안 드립니다' 한 줄 보낸다」 · 「동기화 명령을 친다」가 행동이다. 「보고서를 쓴다」는 행동이 아니다.

**그다음** — 덩이는 2개까지다. 할 일이 6개면 2덩이로 묶고 이름을 붙인다(「행정 마무리 3건」 「10/6 강의 준비」). 덩이마다 소요 시간과 첫 5초 행동을 붙인다.

**결정이 필요한 것** — 번호를 붙이고 선택지를 단다. 여기 올 것은 CLAUDE.md 의 목적·기한과 바깥 사실이 어긋난 것 · 채널끼리 사실이 다른 것 · 목적 밖으로 보이는 todo 항목 · 폴더명(마감) 변경 · 파일 정리다. 없으면 절을 통째로 뺀다.

## 하지 않는 것

- 지난번과 같은 말을 반복하지 않는다. `_agent/start-log.md` 에 지난 브리핑이 있으면 **그때와 달라진 것만** 쓴다.
- 압박하려고 숫자를 쓰지 않는다. 「미완료 14건」은 죄책감만 남기고 행동은 만들지 못한다.
- 기억에 기대게 하지 않는다. 지난 결정은 다시 인용한다: 「8/27 에 정산을 총액 방식으로 정하셨습니다」.

## 예시

아래 프로젝트와 사람은 설명을 위해 지어낸 것이다.

```markdown
# ▶ 2026-10_컨설팅-예시 시작 브리핑 — 2026-09-06

**지난 12일 동안 달라진 것** (측정 실패: 없음)
- 9/3 고객사 담당자가 보고서 형식을 문장으로 확정했다 — 메신저 · 프로젝트 방
- 8/27 대상이 5개사에서 4개사로 줄고, 정산은 총액 방식으로 바뀌었다 — 메신저, CLAUDE.md 반영됨
- 메일은 0건 — 이 프로젝트의 주 채널은 메신저다

**축**: 10월 정산까지 남은 것은 보고서 4건뿐이고, 첫 초안이 나와야 나머지 셋의 형식이 정해진다.

**지금 당장 하나** ⏱ 1시간
A사 보고서 초안을 담당자가 준 세 절(도입 현황 · 문제점 · 개선 방안)로 잡는다.
→ 첫 5초: `03_보고서/` 에 `A사_진단_초안.md` 를 만들고 세 절 제목만 친다.

**그다음** (최대 2덩이)
- **나머지 3사 초안** ⏱ 각 1시간 — A사 판을 복제해 채운다 → 첫 5초: `01_기업자료/사전설문.xlsx` 를 연다
- **정산 확인** ⏱ 10분 — 총액과 회차 수를 문장으로 다시 확인한다 → 첫 5초: 프로젝트 방에 「정산은 총액 방식으로 이해했습니다. 회차는 8회로 잡을까요?」를 보낼 초안을 쓴다

**결정이 필요한 것**
1. 8/13 특강 자료가 `02_소통기록/` 에 있다 — CLAUDE.md 는 범위 밖이라고 했다. ⓐ 그대로 둔다 ⓑ Archive 로 옮긴다(정리계획서)
```
