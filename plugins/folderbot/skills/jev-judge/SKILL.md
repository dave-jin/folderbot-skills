# jev-judge — 분류는 Jev 가 먼저, 애매하면 LLM

**왜 있나.** 인박스 정리처럼 「정해진 선택지 중 하나 고르기」를 큰 LLM 이 건마다 파일을 열어 판단하면 느리고 토큰이 많이 든다. Jev 는 글을 쓰지 않고 선택지마다 확률만 돌려주는 모델이라 한 건에 1초 안쪽이다. 그래서 **쉬운 건은 Jev 가 거르고, 애매한 소수만 LLM 이 연다.** 이름은 카너먼의 시스템 1(빠른 직관)·시스템 2(느린 숙고)에서 왔다 — Jev 가 시스템 1, LLM 이 시스템 2 다.

## 쓰는 법

명령은 이 스킬 폴더의 `scripts/jev` 다. `scripts/setup.sh` 를 한 번 돌렸으면 `jev` 로 부른다.

```bash
export FOLDERBOT_VAULT="<볼트 루트>"   # 없으면 현재 폴더

jev inbox                 # 인박스 항목마다 JSON 한 줄
jev inbox --limit 3       # 앞의 3건만
jev choice --state "파일명: 2026-10_견적서.pdf" \
    --option "강의=강의 프로젝트" --option "재무=세금·정산" --option "모름=단서 부족"
jev status                # 비용 가드 상태·잔액·마지막 점검
jev pricecheck --force    # 무료 조건을 지금 다시 조사
```

## 결과를 읽는 법 — 총괄 LLM 이 할 일

`inbox` 는 항목마다 `band` 를 붙여 돌려준다.

| band | 뜻 | LLM 이 할 일 |
|---|---|---|
| `dup` | 볼트에 같은 파일(sha256 일치)이 이미 있다 | 「중복 — 인박스 사본은 휴지통 후보」로 제안한다 |
| `dup?` | 이름·크기가 같은 사본이 있다(온라인 전용이라 해시는 안 봤다) | 중복일 가능성이 높다고 제안하고, 지우기 전에 사본을 내려받아 해시를 대조한다 |
| `suggest` | 신뢰도 0.9 이상 | 그 목적지 하나를 제안한다 |
| `pick2` | 0.5 ~ 0.9 | `top2` 두 후보를 제안하고 사용자에게 고르게 한다 |
| `llm` | 0.5 미만 · 「모름」 · 「새 프로젝트 필요」 · 민감어 · 오류 · 비용 가드 | **Jev 결과를 버리고 LLM 이 직접 파일을 열어 판단한다** |

* **옮기는 것은 사용자가 승인한 뒤다.** 이 스킬은 판단만 한다.
* **Jev 답을 그대로 믿지 않는다.** 이름만 보고 고른 것이다. `suggest` 도 LLM 이 한 번 훑고, 이상하면 뒤집는다.
* **한두 건이면 부르지 않아도 된다.** LLM 이 이미 대화 중이면 직접 판단이 더 빠르다. 여러 건·루틴·배치에서 부른다.

## 보내는 것과 안 보내는 것

* **보낸다**: 항목 이름(`mask` 로 이름 가림 가능) · 확장자 · 크기 · 폴더면 안에 든 파일 수와 종류 · 선택지로 볼트 폴더 목록과 폴더 이름에서 뽑은 한 줄 설명.
* **안 보낸다**: 파일 본문, readme 내용, 하위 파일 이름. 이름에 민감어(`never_send`)가 든 항목은 **아예 보내지 않고** `llm` 으로 돌린다.
* 로컬 중복 대조는 밖으로 아무것도 보내지 않는다.
* 보내는 곳: Vercel AI Gateway → TypeSafe AI(미국). TypeSafe 는 고객 데이터로 학습하지 않는다고 밝혔다. 보존 기간·보안 인증은 각자 약관에서 확인한다. **폴더 이름에 고객사 이름이 있으면 그 목록이 밖으로 나간다는 점을 알고 쓴다.**

## 비용 가드 — 무료가 끝나면 막는다

2026-09-25 에 Vercel AI Gateway 에서 Jev 호출의 청구액이 0 이었다. 이 조건은 언제든 바뀔 수 있으므로 네 겹으로 지킨다.

1. **호출마다**: 응답의 `cost` 를 본다. 0 보다 크면 그 자리에서 가드를 걸고 다음 호출부터 막는다.
2. **24시간마다 조사**(부를 때 자동): Vercel 모델 목록의 정가 · 무료 등급 표시 · 팀 잔액을 본다. Jev 가 무료에서 빠지거나 목록에서 사라지거나, 잔액이 무료분보다 커지면(= 크레딧을 샀다 = 유료 등급) 막는다.
3. **매일 09:10**(setup.sh 가 건 launchd): 같은 점검을 돌리고, 경고가 있으면 맥 알림과 `~/.local/state/jev-judge/ALERT` 를 남긴다. 이 파일이 있으면 LLM 은 먼저 사용자에게 알린다.
4. **키 한도**: Vercel 키에 월 한도($1 등)를 걸어 둔다. 위가 다 실패해도 그 이상은 못 쓴다.

* 막히면 종료 코드 **3** 과 `engine: "blocked"` 를 돌려준다. **LLM 은 그 사실을 알리고 직접 판단한다.**
* 경고만 원하면 `presets/inbox-filing.json` 의 `cost_guard.policy` 를 `warn` 으로 바꾼다. 확인한 뒤 풀 때는 `jev unblock`.

## 파일

* `scripts/jev` — CLI(Python 3 표준 라이브러리만). 키는 키체인 `ai-gateway` / `jev-judge`.
* `scripts/jev-daily` — 매일 점검. `scripts/setup.sh` — 한 번만 하는 설정.
* `presets/inbox-filing.json` — 질문·기준값·폴더 구조·전송 규칙·비용 정책. **바꿀 것은 여기만 바꾼다.** PARA 가 아닌 볼트는 `folders` 를 고친다.
* 기록: `~/.local/state/jev-judge/calls.jsonl`(호출마다) · `guard.json`(가드 상태). 로컬에만 있다.
